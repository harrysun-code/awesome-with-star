([Website](https://iconify.design))
- [React Icons](https://github.com/react-icons/react-icons#reamde) [![GitHub stars](https://img.shields.io/github/stars/react-icons/react-icons?style=flat)](https://github.com/react-icons/react-icons/stargazers) - Popular icon sets created especially for React projects. ([Website](https://react-icons.github.io/react-icons/))
- [Unicon](https://github.com/WebRenew/unicon#readme) [![GitHub stars](https://img.shields.io/github/stars/WebRenew/unicon?style=flat)](https://github.com/WebRenew/unicon/stargazers) - Browse 20,000+ icons from 9 libraries and copy only what you need—like shadcn/ui for icons.
