# Awesome Observables [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> An [Observable](https://github.com/zenparsing/es-observable) [![GitHub stars](https://img.shields.io/github/stars/zenparsing/es-observable?style=flat)](https://github.com/zenparsing/es-observable/stargazers) is a collection that arrives over time. Observables can be used to model push-based data sources such as events, timer intervals, asynchronous requests, and animations. Observables can be transformed, combined, and consumed using array-like methods.
