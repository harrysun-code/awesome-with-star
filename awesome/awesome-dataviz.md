## JavaScript tools

### Charting libraries
- [Apache ECharts](https://github.com/apache/echarts) [![GitHub stars](https://img.shields.io/github/stars/apache/echarts?style=flat)](https://github.com/apache/echarts/stargazers) - Highly customizable and interactive charts ready for big datasets.
- [ApexCharts](https://apexcharts.com/) - Modern & Interactive SVG Charts.
- [billboard.js](https://github.com/naver/billboard.js) [![GitHub stars](https://img.shields.io/github/stars/naver/billboard.js?style=flat)](https://github.com/naver/billboard.js/stargazers) - Reusable D3.js-based chart library with SVG and Canvas rendering, maintained by NAVER.
- [C3.js](https://github.com/c3js/c3) [![GitHub stars](https://img.shields.io/github/stars/c3js/c3?style=flat)](https://github.com/c3js/c3/stargazers) - D3-based reusable chart library.
- [Cal-Heatmap](https://github.com/wa0x6e/cal-heatmap) [![GitHub stars](https://img.shields.io/github/stars/wa0x6e/cal-heatmap?style=flat)](https://github.com/wa0x6e/cal-heatmap/stargazers) - Time-series calendar heatmaps, similar to GitHub's contribution graph, built on D3.
- [Carbon Charts](https://github.com/carbon-design-system/carbon-charts) [![GitHub stars](https://img.shields.io/github/stars/carbon-design-system/carbon-charts?style=flat)](https://github.com/carbon-design-system/carbon-charts/stargazers) - Chart library from IBM's Carbon Design System, built on D3, with React, Angular, Vue and Svelte wrappers.
- [Chart.js](https://www.chartjs.org/) - Charts with the canvas tag.
- [chart.xkcd](https://github.com/timqian/chart.xkcd) [![GitHub stars](https://img.shields.io/github/stars/timqian/chart.xkcd?style=flat)](https://github.com/timqian/chart.xkcd/stargazers) - Chart library that renders line, bar, pie and other charts in a hand-drawn xkcd style.
- [ChartGPU](https://github.com/ChartGPU/ChartGPU) [![GitHub stars](https://img.shields.io/github/stars/ChartGPU/ChartGPU?style=flat)](https://github.com/ChartGPU/ChartGPU/stargazers) - WebGPU charting library for large datasets, real-time streaming and multi-chart dashboards.
- [Chartist.js](https://gionkunz.github.io/chartist-js/) - Responsive charts with great browser compatibility.
- [Charts.css](https://github.com/ChartsCSS/charts.css) [![GitHub stars](https://img.shields.io/github/stars/ChartsCSS/charts.css?style=flat)](https://github.com/ChartsCSS/charts.css/stargazers) - CSS framework that styles HTML tables as charts.
- [dc.js](https://github.com/dc-js/dc.js) [![GitHub stars](https://img.shields.io/github/stars/dc-js/dc.js?style=flat)](https://github.com/dc-js/dc.js/stargazers) - Multi-dimensional charting built to work natively with crossfilter.
- [DHTMLX Gantt](https://github.com/DHTMLX/gantt) [![GitHub stars](https://img.shields.io/github/stars/DHTMLX/gantt?style=flat)](https://github.com/DHTMLX/gantt/stargazers) - Gantt chart component for project schedules, with task dependencies and drag-and-drop editing.
- [Dygraphs](https://dygraphs.com/) - Interactive line charts library that works with huge datasets.
- [ECharts GL](https://github.com/ecomfe/echarts-gl) [![GitHub stars](https://img.shields.io/github/stars/ecomfe/echarts-gl?style=flat)](https://github.com/ecomfe/echarts-gl/stargazers) - Extension for Apache ECharts that adds 3D plots, globe visualizations and WebGL-accelerated series.
- [Epoch](https://github.com/epochjs/epoch) [![GitHub stars](https://img.shields.io/github/stars/epochjs/epoch?style=flat)](https://github.com/epochjs/epoch/stargazers) - Perfect to create real-time charts.
- [Flot](https://github.com/flot/flot) [![GitHub stars](https://img.shields.io/github/stars/flot/flot?style=flat)](https://github.com/flot/flot/stargazers) - jQuery plotting library for line, bar and pie charts with zooming and other interactive features.
- [Frappe Charts](https://github.com/frappe/charts) [![GitHub stars](https://img.shields.io/github/stars/frappe/charts?style=flat)](https://github.com/frappe/charts/stargazers) - Simple, responsive SVG charts with zero dependencies.
- [Frappe Gantt](https://github.com/frappe/gantt) [![GitHub stars](https://img.shields.io/github/stars/frappe/gantt?style=flat)](https://github.com/frappe/gantt/stargazers) - Simple, interactive SVG Gantt chart library.
- [G2](https://github.com/antvis/G2) [![GitHub stars](https://img.shields.io/github/stars/antvis/G2?style=flat)](https://github.com/antvis/G2/stargazers) - An interactive and responsive charting library based on the grammar of graphics, maintained by Alibaba.
- [Glyph](https://github.com/seanhanca/glyph) [![GitHub stars](https://img.shields.io/github/stars/seanhanca/glyph?style=flat)](https://github.com/seanhanca/glyph/stargazers) - Deterministic chart library that renders the same JSON spec to identical SVG on every platform, with DuckDB inside and an MCP server for AI agents.
- [Google Charts](https://developers.google.com/chart) - Interactive charts for browsers and mobile devices.
- [GraphicsJS](http://www.graphicsjs.org) - Lightweight JS graphics library with intuitive API, based on SVG/VML.
- [heatmap.js](https://github.com/pa7/heatmap.js) [![GitHub stars](https://img.shields.io/github/stars/pa7/heatmap.js?style=flat)](https://github.com/pa7/heatmap.js/stargazers) - Canvas-based library for rendering heatmaps, with plugins for Leaflet and Google Maps.
- [lit-line](https://github.com/apinet/lit-line) [![GitHub stars](https://img.shields.io/github/stars/apinet/lit-line?style=flat)](https://github.com/apinet/lit-line/stargazers) - SVG Line Chart Web Component - light, fast, interactive & fully responsive.
- [MetricsGraphics.js](https://metricsgraphicsjs.org/) - Optimized for time-series data.
- [NVD3](https://github.com/novus/nvd3) [![GitHub stars](https://img.shields.io/github/stars/novus/nvd3?style=flat)](https://github.com/novus/nvd3/stargazers) - A reusable charting library written in d3.js.
- [Observable Plot](https://github.com/observablehq/plot) [![GitHub stars](https://img.shields.io/github/stars/observablehq/plot?style=flat)](https://github.com/observablehq/plot/stargazers) - A JavaScript library for exploratory data visualization.
- [Plotly.js](https://github.com/plotly/plotly.js/) [![GitHub stars](https://img.shields.io/github/stars/plotly/plotly.js/?style=flat)](https://github.com/plotly/plotly.js//stargazers) - Powerful declarative library with support for 20 chart types.
- [roughViz](https://github.com/jwilber/roughViz) [![GitHub stars](https://img.shields.io/github/stars/jwilber/roughViz?style=flat)](https://github.com/jwilber/roughViz/stargazers) - Sketchy, hand-drawn style charts for the browser, based on Rough.js.
- [TOAST UI Chart](https://github.com/nhn/tui.chart) [![GitHub stars](https://img.shields.io/github/stars/nhn/tui.chart?style=flat)](https://github.com/nhn/tui.chart/stargazers) - Complete library with support for legacy browsers.
- [Unovis](https://github.com/f5/unovis) [![GitHub stars](https://img.shields.io/github/stars/f5/unovis?style=flat)](https://github.com/f5/unovis/stargazers) - Modular data visualization framework for React, Angular, Svelte, Vue and vanilla TypeScript, by F5.
- [uPlot](https://github.com/leeoniya/uPlot) [![GitHub stars](https://img.shields.io/github/stars/leeoniya/uPlot?style=flat)](https://github.com/leeoniya/uPlot/stargazers) - Small, fast canvas-based charts for time series, lines, areas, OHLC and bars.
- [VChart](https://github.com/VisActor/VChart) [![GitHub stars](https://img.shields.io/github/stars/VisActor/VChart?style=flat)](https://github.com/VisActor/VChart/stargazers) - Cross-platform charting library with animation and storytelling features, from ByteDance's VisActor.
- [Vizzu](https://github.com/vizzuhq/vizzu-lib) [![GitHub stars](https://img.shields.io/github/stars/vizzuhq/vizzu-lib?style=flat)](https://github.com/vizzuhq/vizzu-lib/stargazers) - Library for animated data visualizations and data stories.

- [JointJS](https://github.com/clientIO/joint) [![GitHub stars](https://img.shields.io/github/stars/clientIO/joint?style=flat)](https://github.com/clientIO/joint/stargazers) - SVG-based JavaScript diagramming library for interactive diagrams and graph editors.
- [Sigma.js](https://sigmajs.org/) - JavaScript library dedicated to graph drawing.
- [Uber React Digraph](https://github.com/uber/react-digraph) [![GitHub stars](https://img.shields.io/github/stars/uber/react-digraph?style=flat)](https://github.com/uber/react-digraph/stargazers) - React.js based directed graph library maintained by UBER.
- [VivaGraph](https://github.com/anvaka/VivaGraphJS) [![GitHub stars](https://img.shields.io/github/stars/anvaka/VivaGraphJS?style=flat)](https://github.com/anvaka/VivaGraphJS/stargazers) - Graph drawing library for JavaScript.
- [Viz.js](https://github.com/mdaines/viz-js) [![GitHub stars](https://img.shields.io/github/stars/mdaines/viz-js?style=flat)](https://github.com/mdaines/viz-js/stargazers) - Graphviz compiled to WebAssembly for rendering DOT graphs in the browser and Node.js.
- [Vizdom](https://github.com/vizdom-dev/vizdom) [![GitHub stars](https://img.shields.io/github/stars/vizdom-dev/vizdom?style=flat)](https://github.com/vizdom-dev/vizdom/stargazers) - A declarative graph layout and rendering engine for Javascript/Typescript powered by Rust/WebAssembly.
- [Vue Flow](https://github.com/bcakmakoglu/vue-flow) [![GitHub stars](https://img.shields.io/github/stars/bcakmakoglu/vue-flow?style=flat)](https://github.com/bcakmakoglu/vue-flow/stargazers) - Flowchart and node-based graph component for Vue 3.
- [X6](https://github.com/antvis/X6) [![GitHub stars](https://img.shields.io/github/stars/antvis/X6?style=flat)](https://github.com/antvis/X6/stargazers) - Diagramming library for DAGs, ER diagrams, flowcharts and other graph editors, maintained by Alibaba.
- [xyflow](https://github.com/xyflow/xyflow) [![GitHub stars](https://img.shields.io/github/stars/xyflow/xyflow?style=flat)](https://github.com/xyflow/xyflow/stargazers) - React Flow and Svelte Flow: libraries for building node-based editors, flow charts and interactive diagrams.
