## Emulators
- [Android Emulator](https://developer.android.com/studio/run/emulator) - Official Android emulator integrated into Android Studio.
- [Genymotion](https://www.genymotion.com) - Fast Android emulator for app testing and development. *Commercial*

## Libraries

### Jetpack Compose

- [Jetpack Compose](https://developer.android.com/compose) - Modern toolkit for building native Android UI with declarative Kotlin APIs and Material 3 support.

### Architecture

- [Circuit](https://github.com/slackhq/circuit) [![GitHub stars](https://img.shields.io/github/stars/slackhq/circuit?style=flat)](https://github.com/slackhq/circuit/stargazers) - Modern architecture framework for building Android apps with Compose.
- [Decompose](https://github.com/arkivanov/Decompose) [![GitHub stars](https://img.shields.io/github/stars/arkivanov/Decompose?style=flat)](https://github.com/arkivanov/Decompose/stargazers) - Kotlin Multiplatform library for breaking down your code into lifecycle-aware business logic components.

### Charts

- [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart) [![GitHub stars](https://img.shields.io/github/stars/PhilJay/MPAndroidChart?style=flat)](https://github.com/PhilJay/MPAndroidChart/stargazers) - An Android chart and graph library supporting scaling and dragging by gesture.
- [Vico](https://github.com/patrykandpatrick/vico) [![GitHub stars](https://img.shields.io/github/stars/patrykandpatrick/vico?style=flat)](https://github.com/patrykandpatrick/vico/stargazers) - Modern chart library with support for both Jetpack Compose and Android Views.

### Data binding

- [Data Binding Library](https://developer.android.com/topic/libraries/data-binding/) - Official Android Data Binding Library to write declarative layouts and minimize the glue code necessary to bind application logic and layouts.

### Dependency Injection

- [Hilt](https://developer.android.com/training/dependency-injection/hilt-android) - Official dependency injection library built on top of Dagger for Android.
- [Dagger 2](https://github.com/google/dagger) [![GitHub stars](https://img.shields.io/github/stars/google/dagger?style=flat)](https://github.com/google/dagger/stargazers) - A fast dependency injector for Android and Java.
- [Koin](https://insert-koin.io/) - Lightweight dependency injection framework for Kotlin.

### Game Development

- [Libgdx](https://libgdx.com/) - Cross-platform game engine and SDK. [Open Source](https://github.com/libgdx/libgdx) [![GitHub stars](https://img.shields.io/github/stars/libgdx/libgdx?style=flat)](https://github.com/libgdx/libgdx/stargazers)
- [Godot](https://github.com/godotengine/godot) [![GitHub stars](https://img.shields.io/github/stars/godotengine/godot?style=flat)](https://github.com/godotengine/godot/stargazers) - Cross-platform 2/3D game engine with an IDE and under MIT license.
- [Vuforia](https://www.ptc.com/en/products/vuforia) - Augmented Reality library. *Commercial*
- [Unity](https://unity.com/features/multiplatform) - Cross-platform game creation system. *Commercial*

### Security

- [Google Tink](https://github.com/tink-crypto/tink-java) [![GitHub stars](https://img.shields.io/github/stars/tink-crypto/tink-java?style=flat)](https://github.com/tink-crypto/tink-java/stargazers) - Multi-language cross-platform cryptography library providing secure APIs for common cryptographic tasks.

### Crash monitoring

## Development Alternatives

My personal recommendation is (for now) to use the Android SDK to build a native app. Scala and Kotlin are both options; multidex requirements depend on an app's method-reference count and minimum SDK level, not its language. Cross-platform alternatives can also be useful when they fit a project's requirements.
